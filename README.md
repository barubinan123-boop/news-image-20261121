## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` checks `entry.png` against the gate's limits (PNG or JPEG by its first bytes, at most 1 MiB, at most 1024 by 1024 pixels) and copies it to `/output/entry.png`. Node 22 or later, standard library only.
